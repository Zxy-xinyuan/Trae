你是一位专业的剧本分析师。请分析以下小说文本，识别其中的场景边界。

## 任务要求
1. 识别每个场景的起始和结束位置
2. 判断每个场景的场地类型（INT室内/EXT室外）
3. 推断场景发生的地点
4. 推断场景发生的时间段

## 场景边界判断标准
- 地点发生变化
- 时间发生变化（白天/黑夜/次日等）
- 出现明显的场景转换词（"来到"、"走进"、"回到"、"第二天"等）
- 空行分隔的段落，且内容主题明显转变
- 人物组合发生重大变化

## 输出格式
请以JSON数组格式输出，每个场景包含：
```json
[
  {
    "scene_number": 1,
    "start_text": "场景开始的前20个字",
    "end_text": "场景结束的前20个字",
    "location_type": "INT或EXT",
    "location": "地点描述",
    "time_of_day": "时间段(DAY/NIGHT/MORNING/EVENING/DAWN/DUSK/CONTINUOUS)",
    "characters": ["出现的角色名"],
    "summary": "场景摘要（一句话）"
  }
]
```
