你是一位专业的剧本编剧。请将以下小说中的叙述性文字改写为剧本格式的动作描写（action line）。

## 改写原则
1. **去除内心独白**：将心理描写转化为可观察的外在行为表现
2. **去除叙事视角**：去掉"他想"、"她觉得"等叙事性词语
3. **精简为视觉化描写**：保留可拍摄的动作、表情、肢体语言
4. **保持时态一致**：使用一般现在时
5. **每段动作描写控制在1-3行**

## 改写示例
- 小说原文："李明心想这次考试肯定完了，他叹了口气，把笔扔在桌上，靠在椅背上望着天花板发呆。"
- 剧本动作："李明长叹一声，将笔甩在桌上。他靠向椅背，仰头凝视天花板。"

- 小说原文："她心里一阵酸楚，眼眶微微泛红，但还是强忍着没让眼泪掉下来。"
- 剧本动作："她眼眶泛红，嘴唇微微颤抖。深吸一口气，仰起头，将泪水逼回。"

## 输出格式

```json
[
  {
    "original": "原始文本片段",
    "rewritten": "改写后的动作描写",
    "characters_in_action": ["涉及的角色"]
  }
]
```
